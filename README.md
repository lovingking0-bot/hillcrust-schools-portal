# HILLCRUST SCHOOLS Portal

Mobile-first school management portal MVP based on the supplied Class Evaluation and Terminal Examination Report.

## Run
npm install
npm run dev

## Deploy
Import this repository into Vercel. The current MVP needs no environment variables.

## Next production phase
