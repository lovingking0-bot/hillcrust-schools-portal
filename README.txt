HILLCRUST SCHOOLS PORTAL - UPGRADE

Files replace the existing app/page.js, app/globals.css, app/layout.js and package.json.

This version adds:
- Student registration stored in browser local storage
- Student search
- Result entry for all supplied subjects
- CA 30% + Exam 70% grading
- Result save on the device
- Print / Save as PDF
- Admissions, attendance, fees and settings foundations

IMPORTANT: This is the front-end upgrade. It is not yet a multi-user production database system. The next phase is database + authentication + roles.
